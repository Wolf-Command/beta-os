# NAS in-place indexer — 26 Sep 2026

Beta only. Reads the 25 Sep discovery manifest. Does not rescan the estate unless that manifest is missing. Does not move, rename, delete, or write inside a NAS media tree. Production :8787 is not part of this run.

`staff_ready` stays false. `full_nas_complete` stays false. A caught-up catalog is the manifest row count, not a claim that the whole NAS is complete.

## What it does

1. Upserts `state/nas-estate/manifest.tsv` into `catalog/content_library.sqlite` table `nas_index`.
2. Maps folder names through `org_brand_aliases` (Brand Registry). Unknown stays `UNKNOWN`. Stock roots stay `SHARED_STOCK`.
3. State order: `DISCOVERED` → `INDEXED` → `THUMB_PREVIEW_READY` (thumb/preview ready) → `SEARCHABLE` → `HASHED`. A bad file is `FAILED` and the run continues.
4. Thumbnails go to the existing cache `state/content-thumbs/nas-<id>.jpg` via `sips` (images) or `ffmpeg` (video).
5. Same name+size, and same first-1MB sha256, are recorded as duplicate candidates. Nothing on the NAS is deleted.
6. Owner counts: `state/nas-estate/owner-counts.json` (brand × state).
7. Library search on Beta :8788 (`/api/assets`) queries indexed rows and pages them. It does not return only the old 24-card sample.

Hashing stores the first 1MB in `sha256_1mb` (`hash_partial=1` when the file is larger). That is not a full-file hash.

## Run

From `/Users/wolfterminal/beta-os`:

```bash
python3 scripts/nas_estate_index.py
```

Detached (keeps going after the terminal exits):

```bash
mkdir -p state/nas-estate
nohup python3 scripts/nas_estate_index.py >> state/nas-estate/index.log 2>&1 &
echo $! > state/nas-estate/index.pid
```

The script also writes its own pid. If that pid is still alive, a second start exits without a second run.

## Resume

If the process is killed, start the same command again. It reads `index-checkpoint.json` and continues from the last committed manifest line, then from rows still in `INDEXED`, `THUMB_PREVIEW_READY`, or `SEARCHABLE`. Rows already `HASHED` or `FAILED` are not walked backward. A changed manifest file size starts the line cursor at 0; upserts do not duplicate `original_path`.

Stop with `kill` on the pid in `index.pid`. Do not delete NAS files to stop it.
